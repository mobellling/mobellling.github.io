MobellSite 1.0.0（Windows x64 免安装版）
=================================================

一、运行方式
------------
1. 将本压缩包解压到任意目录（例如 D:\Apps\MobellSite）。
2. 双击解压目录中的 MobellSite.exe 即可运行，无需安装。
3. 程序需要联网时优先加载在线站点 https://mobellling.github.io/ ；
   断网或站点不可用时自动回退到内置网站快照，实现完整离线浏览。

二、常见提示
------------
1. Windows SmartScreen：本程序未做代码签名。首次运行时若出现
   “Windows 已保护你的电脑”，请点击“更多信息”→“仍要运行”。
2. 杀毒软件误报：Electron 应用偶有误报，请将解压目录加入信任列表。

三、数据与卸载
--------------
1. 用户数据（窗口位置、站点基线、通知设置等）保存在
   %APPDATA%\MobellSite\ ，日志为其中的 app.log。
2. 卸载：直接退出程序并删除整个 MobellSite 目录即可；如需彻底清理，
   可再删除 %APPDATA%\MobellSite\ 目录。
3. 程序不会写入系统目录，也不会创建服务或驱动。

四、更新方式
------------
1. 网站内容更新：程序每 60 秒（窗口在前台）或 300 秒（后台）检测
   https://mobellling.github.io/_hash ，发现变化时弹出系统通知和页面
   提示条，点击刷新即可看到最新内容。
2. 软件更新：程序启动时及每 6 小时检查
   https://mobellling.github.io/app/latest.json ，发现新版本会在系统
   通知中给出下载链接（在浏览器中打开）。本程序不会自动下载安装，
   请下载新的压缩包后解压覆盖到新目录使用。
3. 也可通过托盘图标右键菜单或应用菜单“更新”手动检查。

五、离线说明
------------
1. 内置快照来自构建时的站点完整导出（含文章、图片、搜索索引）。
2. 在线主文档加载失败（断网、DNS 失败、20 秒超时）时自动进入离线
   模式，页面顶部显示“离线模式 · 正在显示内置网站快照”提示条。
3. 点击提示条中的“重新连接”可切回在线站点；恢复联网后再次点击即可。
4. 离线模式下文章、分类、标签、关于与站内搜索均可正常使用。

六、托盘与退出
--------------
1. 点击窗口关闭按钮不会退出程序，而是最小化到系统托盘（首次会提示）。
2. 托盘图标右键菜单可显示/隐藏窗口、检查更新或退出。
3. 需要完全退出时，请使用托盘菜单“退出”或应用菜单“文件 → 退出”。

七、自检与通知测试
------------------
1. 命令行运行 MobellSite.exe --selftest ，会输出一行 JSON 自检结果
   （ok、hashStatus、updateStatus、snapshotFiles 等），成功退出码为 0。
   结果同时写入 %TEMP%\mobellsite-selftest.json 。
2. 运行 MobellSite.exe --test-notify ，会发送一条“网站已更新”测试通知，
   5 秒后自动退出，用于验证系统通知是否正常。
3. 若系统通知被关闭，程序仍会在页面内显示相应提示条，不影响使用。

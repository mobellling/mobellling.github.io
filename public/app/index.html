MobellSite 客户端

把网站装进应用：完整功能、离线快照、网站更新提醒、软件更新检查。

Windows 免安装

版本 1.0.0 · 压缩包
SHA-256 见下载页更新

下载 Windows 压缩包
  • 适用 Windows 10 / 11（x64）
  • 解压后双击 MobellSite.exe 即可运行
  • 关闭窗口会最小化到托盘，右键托盘图标可退出
  • 内置网站离线快照，断网也能浏览已发布的内容

Android APK

版本 1.0.0 · 安装包
SHA-256 见下载页更新

下载 Android APK
  • 适用 Android 7.0 及以上（无 Google 服务依赖）
  • 安装时如提示「未知来源」，允许浏览器/文件管理器安装即可
  • 支持离线浏览、网站更新与软件更新通知
  • 首次启动会请求通知权限，拒绝后仍可在应用内看到更新提示

更新方式

网站有新内容时，应用会弹出「网站已更新」提醒，点击即可刷新到最新内容。软件自身更新会提示新版本号，点击后在浏览器下载新的 zip / APK 覆盖安装即可。

iOS 版本将在后续提供。所有安装包均托管在 GitHub Releases。
